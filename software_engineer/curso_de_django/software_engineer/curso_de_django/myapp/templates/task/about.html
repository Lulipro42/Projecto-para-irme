Sobre este Proyecto

Bienvenido a mi plataforma de gestión. Mi nombre es Ulises. Este proyecto nació con el objetivo de diseñar un entorno eficiente para administrar tareas y proyectos globales, aplicando buenas prácticas de desarrollo web, optimización de bases de datos y diseño adaptable.

💻 Backend & DB

Desarrollado con Python y Django, aprovechando su sistema de rutas, vistas basadas en funciones y un sólido ORM para la persistencia de datos de forma segura.

🎨 UI & UX Líquida

Maquetado limpio utilizando CSS Grid y Flexbox. Cuenta con un sistema dinámico de variables para soportar Modo Claro y Modo Oscuro de forma nativa.

🎯 Objetivos

Centralizar el flujo de trabajo personal, controlar estados de tareas (pendientes, completadas, vencidas) y dominar la arquitectura de software de extremo a extremo.
